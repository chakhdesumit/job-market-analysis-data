# Job Market Analysis (Data Science Salaries)

This project explores global data science job salaries using Exploratory Data Analysis (EDA).

The goal is to understand how factors like experience level, company size, location, and remote work impact salary.

---

## Analysis Performed

- Salary Distribution  
- Salary vs Experience Level  
- Salary vs Company Size  
- Salary by Country (Top 10)  
- Remote Work Impact on Salary  
- Salary Trend Over Time  
- Correlation Analysis  

---

## Key Insights

- Salaries increase significantly with experience level.  
- Medium and large companies tend to offer higher salaries.  
- Salary levels vary across countries, with some offering higher compensation than others.  
- Fully remote roles generally offer better pay compared to hybrid roles.  
- Salaries have increased over time, indicating growing demand in the data field.  
- Multiple factors together influence salary rather than any single variable.
